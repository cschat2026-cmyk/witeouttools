Decision notes:

- Whiteout Survival is the recommended project because it combines a large global strategy audience with recurring event loops, alliance coordination, resource planning, gift code searches, and calculator/checklist needs.
- Last War: Survival is a strong alternative, but the first content wedge is more crowded around hero lists and codes.
- Clash of Clans is evergreen, but mature calculator/wiki competitors already own many high-intent keywords.
- Mobile Legends: Bang Bang has huge community activity, but long-term site quality depends on frequent tier-list and esports editorial work.

Content reliability policy:

- Official: directly from official site, official social, or in-game notices.
- Community: player reports, code trackers, Reddit/Discord/Facebook reports.
- Inference: planning advice derived from recurring event structure or common strategy patterns.

The current code list uses explicit `active`, `expired`, and source-backed status labels based on the latest public references gathered for this update.
