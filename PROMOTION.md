# Whiteout Survival Tools Promotion Playbook

Domain used below: `https://witheout20.top`

## Goal

Get the first repeat users from channels where Whiteout Survival players already gather, while avoiding spammy behavior that gets links removed or accounts muted.

## What to lead with

Do not introduce the site as a generic "fan portal". Lead with the three fastest hooks that match repeated player jobs:

1. Gift code copy board
2. Frostfire Mine timer
3. Fire Crystal / Furnace resource planner

Those are the easiest features to explain in one sentence, the easiest to demonstrate in a short clip, and the most likely to create repeat visits.

## Channel priority

### Priority 1: Reddit

Why first:

- `r/whiteoutsurvival` already contains gift-code posts, planner/tool posts, and "new player" help threads.
- Players are used to replying with whether a code worked or expired, which fits this site well.
- Reddit links can be indexed and can send the first real feedback quickly.

How to behave:

- Post as a fan utility, not as an "official source".
- Ask for server/date expiry feedback.
- Do not cross-post the same text repeatedly.
- Do not mass-DM users.

### Priority 2: Discord alliances and Whiteout communities

Why second:

- Whiteout Survival's official Facebook posts repeatedly direct players to the official Discord invite.
- Alliance and state channels are where players actively ask for timers, codes, and event prep help.

How to behave:

- Share only in channels that allow tools, guides, or community resources.
- Lead with one helpful use case, not a site pitch.
- Never blast the same message into many channels in a short window.

### Priority 3: Facebook groups

Why third:

- The official Whiteout Survival Facebook page is active and points players to Discord.
- Facebook groups are strong for broad reach, especially for code and event reminder posts.

How to behave:

- Post as a player-made helper.
- Use one useful screenshot.
- Ask a simple question to drive comments, such as "which code worked on your server today?"

### Priority 4: YouTube Shorts / TikTok

Why fourth:

- The product is easy to demo in under 20 seconds.
- Short clips can be reused across multiple platforms.
- Search intent around gift codes and planning is strong enough that small clips can keep pulling views.

How to behave:

- Keep clips tight and practical.
- Show the action in the first two seconds.
- Put the URL in the description and pinned comment, not as giant on-screen text.

### Day 1: Stay in the thread and reply

For the first 24 hours, check replies and respond quickly.

Use these reply templates:

`Thanks, that helps. I will keep it active for now and note the server/date pattern if more players report the same result.`

Expired code:

`Good catch. I will move it toward expired once I get a couple more server reports. Some code windows seem to close by region or timing, so I am trying to label them conservatively.`

Not official:

`Yes, this is a fan-made utility site, not an official Whiteout Survival site. I separate official info from community reports and planning estimates so players can judge confidence more easily.`

Why use this instead of redeem page only:

`The redeem page is still the official place to claim rewards. This site is mainly for tracking likely active codes, timing Frostfire, and planning Fire Crystal jumps without bouncing between chats and spreadsheets.`

## 30-minute daily routine after launch

Every day for the first 14 days:

1. Check whether any post/comment got replies.
2. Reply to code-validity comments.
3. Update expired / active labels if needed.
4. Share one useful reply in one thread instead of creating a new promo post every day.
5. Save the best user wording from comments. Those phrases should become future page copy and SEO phrases.

## What not to do

- Do not pretend to be official.
- Do not post the same exact text across many places in one hour.
- Do not DM alliance leaders cold with just a link.
- Do not lead with ads, monetization, or "please support".
- Do not drop a naked homepage link without saying what problem it solves.

## What success looks like in week 1

Good signs:

- Players comment whether codes worked or expired
- Players ask for more tools or more data
- Players mention a second use case beyond codes
- Some visits come back the next day

Weak signs:

- Only clicks, no comments
- Users think it is just another code list
- Nobody mentions planner/timer usefulness

If the weak signs happen, change the pitch from "portal" to "specific helper" and lead harder with one use case per post.

- Reddit's help center says promotional content is not automatically spam, but repeated unwanted actions are spam, and some communities use a 10% self-promo rule.

- `r/whiteoutsurvival` already contains gift-code posts, new-player help threads, and tool/planner posts, so players there already understand this kind of utility.
